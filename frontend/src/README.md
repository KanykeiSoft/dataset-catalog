# Dataset Catalog

A simple full-stack application built with React (TypeScript) and .NET Web API.

## Features

- Fetch datasets from API
- Search and filter datasets
- Domain-based filtering
- AI-generated insights
- Clean UI

## Tech Stack

- Frontend: React + TypeScript
- Backend: .NET Web API

## How to run

### Backend
cd DatasetApi
dotnet run

### Frontend
cd frontend
npm install
npm run dev

## API Endpoint

GET /api/datasets
