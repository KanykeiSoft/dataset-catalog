# Dataset Catalog

This is a simple full-stack application built as part of a take-home assessment.

## Tech Stack
- Frontend: React + TypeScript
- Backend: ASP.NET Core (.NET)
- API: REST

## Features
- Display a list of datasets
- Search datasets by name
- Filter datasets by domain
- Simple AI insight for each dataset

## How to run the project

### Backend
cd DatasetApi
dotnet run

### Frontend
cd frontend
npm install
npm start

## API Endpoint
GET /api/datasets
